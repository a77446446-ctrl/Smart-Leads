Локальная среда: Node.js 25.2.1. Целевая версия Node.js 22 указана в engines, Dockerfile и CI; в этой проверке Docker и CI на Node.js 22 не запускались. Пакеты не обновлялись.

Установку зависимостей и сборку пришлось повторить с разрешённым выходом из песочницы: Windows возвращала EPERM при создании node_modules/.prisma. Конфликт родительского ESLint устранён через root: true, выбор родительского корня Next.js — через outputFileTracingRoot.

Сохранение настроек, отказы доступа и валидация проверены настоящими обработчиками API с подменённым хранилищем в памяти. Проверка с новой PostgreSQL, настоящей MAX-сессией, загрузкой логотипа и внешними доставками ещё не выполнена. Автоматическая проверка разрешения снимка экрана завершилась тайм-аутом; пиксельная проверка интерфейса не подтверждена.

После добавления демо-страницы повторная production-сборка не была подтверждена: операции записи завершались EPERM в песочнице. Причина как блокировка файлов другим процессом не доказана. Код прошёл typecheck, lint и профильные тесты.

При исправлении запуска демо подтверждено: на порту 3100 работала старая production-сборка, в которой демо отключено. Старый предпросмотр остановлен; с разрешением запущен сервер разработки коммерческой копии на 127.0.0.1:3100. В открытом браузере проверены появление кнопки «Войти в тестовый режим», переход по нажатию на `/demo`, учебные заявки и статистика. Получен снимок демо-интерфейса. Добавлена команда `npm run demo` для повторного запуска. Стандартный каталог `.next` восстановлен в конфигурации; production-сборка повторно не проверялась.

## Полноценный локальный кабинет

Установлен официальный portable PostgreSQL 16.15 в `C:\SmartLeadsRuntime`; база слушает только `127.0.0.1:55432`. Создана база `smart_leads_local`, сгенерирован `.env.local`, применены 13 миграций и добавлены тестовые администратор, пользователи, категории, лиды, подписка и операция. Повторный `npm run setup:local` успешно подтвердил идемпотентность.

На чистой базе обнаружено отставание исходной истории миграций от Prisma-схемы. Добавлена сохраняющая данные миграция `20260913010000_schema_alignment`: она создаёт недостающие поля и индексы, приводит денежные поля к текущим целочисленным типам и оставляет старые столбцы на месте.

В браузере подтверждены реальный локальный вход через `/api/dev/login`, загрузка `/admin`, статистика 490 ₽ / 3 лида / 3 пользователя / 1 подписка, список трёх категорий, раздел настроек с MAX-аккаунтами и очередью чатов, а также успешные HTTP 200 от административных API. Локальный вход создаёт сессию для реальной записи User и всегда отключён в production.
