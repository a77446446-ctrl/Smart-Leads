# Этап 1: MAX-авторизация и стартовый баланс

## Архитектура

Mini App получает launch-параметры через официальный MAX Bridge. Сервер проверяет HMAC-подпись и время `auth_date`, связывает профиль с цифровым `maxId` и выдаёт подписанную `HttpOnly` cookie. Клиентские `userId`, баланс и роль не считаются доверенными данными.

## Обязательные переменные Coolify

- `MAX_BOT_TOKEN` — токен бота MAX.
- `AUTH_SESSION_SECRET` — случайная строка длиной минимум 32 символа.
- `ADMIN_MAX_IDS` — MAX ID администраторов через запятую.
- `ONBOARDING_BONUS_KOPECKS=30000` — 300 ₽ в целых копейках.
- `NEXT_PUBLIC_APP_URL` — постоянный HTTPS-домен Mini App.
- `CRON_SECRET` — секрет внутреннего планировщика.
- `INGEST_SECRET` — Bearer-секрет внешнего API загрузки лидов.

Секреты должны храниться только в Environment Variables Coolify. После изменения `AUTH_SESSION_SECRET` все активные пользовательские сессии становятся недействительными.

## Первый переход на Prisma Migrate

Перед командами обязательно создать резервную копию PostgreSQL.

Проект раньше использовал `prisma db push`, поэтому для существующей базы сначала следует проверить статус:

```bash
npx prisma migrate status
```

Если таблицы приложения уже существуют, но baseline `20260823000000_baseline` ещё не зарегистрирован:

```bash
npx prisma migrate resolve --applied 20260823000000_baseline
npm run db:deploy
```

Для полностью пустой PostgreSQL выполнять `resolve` нельзя — достаточно:

```bash
npm run db:deploy
```

Команда сначала создаст исходную схему, затем применит миграцию `20260823010000_stage_1_max_auth`.

## Проверка после выкладки

1. Открыть Mini App только кнопкой из официального MAX-бота.
2. Убедиться, что профиль создан с правильным цифровым MAX ID.
3. Проверить баланс 300 ₽.
4. Закрыть и повторно открыть Mini App: второй бонус начисляться не должен.
5. Проверить, что обычный пользователь получает `403` на `/api/admin/*`.
6. Проверить, что контакты в общей ленте скрыты сервером.
7. Купить тестовый лид и убедиться, что контакт появился только в «Моих лидах», а баланс списался один раз.
8. Повторить покупку и параллельный запрос: двойное списание недопустимо.
9. Проверить QR-вход аккаунта-сборщика и ручной запуск парсера.

## Откат

Миграция добавляет столбцы и не удаляет старые денежные поля, поэтому предыдущую версию приложения можно временно вернуть без удаления данных. Автоматически удалять новые столбцы при откате нельзя: сначала требуется резервная копия и отдельная согласованная миграция.
