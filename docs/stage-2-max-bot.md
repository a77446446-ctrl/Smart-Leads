# Этап 2: MAX Bot, каналы-витрины и уведомления

## Архитектура

Лид и задания на отправку сообщений сохраняются одной транзакцией PostgreSQL. Отдельный диспетчер забирает задания из `BotDelivery`, блокирует их оптимистично, отправляет через `https://platform-api2.max.ru/messages` и повторяет временные ошибки с экспоненциальной задержкой. Недоступность MAX не блокирует парсер и не приводит к потере лида.

Публичные тизеры всегда проходят серверное скрытие телефонов, ссылок, email и username. Полный текст получает только пользователь, который успешно купил лид.

## Переменные Coolify

- `MAX_BOT_TOKEN` — токен чат-бота.
- `MAX_BOT_USERNAME` — имя бота без `@`; используется в `startapp` deep link.
- `MAX_WEBHOOK_SECRET` — случайная строка из `A-Z`, `a-z`, `0-9`, `_`, `-`, длина 5–256 символов.
- `NEXT_PUBLIC_APP_URL` — постоянный HTTPS-домен без нестандартного порта.
- `CRON_SECRET` — Bearer-секрет внутреннего диспетчера.

Секрет webhook и `CRON_SECRET` должны отличаться. Не храните их в настройках интерфейса или Git.

Если образ Coolify не доверяет сертификату API MAX, добавьте официальный сертификат Минцифры в образ/volume и задайте `NODE_EXTRA_CA_CERTS` на путь к PEM-файлу. Не отключайте TLS-проверку.

## Выкладка

1. Создать резервную копию PostgreSQL.
2. Применить миграцию:

```bash
npm run db:deploy
```

3. Пересобрать и запустить приложение. Команда `npm start` запускает Next.js и внутренний watchdog; диспетчер обращается к `/api/internal/bot/dispatch` каждые 5 секунд.
4. После успешного healthcheck зарегистрировать webhook:

```bash
npm run bot:webhook
```

Webhook будет установлен на:

```text
https://<домен>/api/webhooks/max
```

Endpoint принимает события только с точным заголовком `X-Max-Bot-Api-Secret` и ограничивает тело 64 КиБ.

## Настройка витрины

1. Добавить бота в канал MAX.
2. Назначить бота администратором с правом публикации.
3. Дождаться события `bot_added`: приложение сохранит числовой `chat_id` в `MaxBotChat`.
4. Открыть «Админка → Категории».
5. Включить «Публиковать в MAX», выбрать найденный `chat_id` и тип витрины.
6. Сохранить категорию.

Для каждой категории задаётся собственный канал. Публичный и приватный канал отправляются одинаковым безопасным методом `chat_id`; тип хранится для администрирования.

## Пользовательский сценарий

1. Пользователь запускает бота. Событие `bot_started` привязывает диалог к `maxId` и включает доставку.
2. В Mini App пользователь выбирает категории в блоке «Новые лиды в MAX».
3. Новый лид создаёт задания для канала-витрины и подписанных пользователей.
4. Кнопка «Забрать контакт» открывает `startapp=lead_<uuid>` и нужную карточку.
5. После покупки отдельное сообщение с полным контактом открывает `startapp=purchase_<uuid>` в «Моих лидах».
6. `bot_stopped`, `dialog_removed` и `dialog_muted` автоматически выключают пользовательские уведомления.

## Проверка после выкладки

1. Выполнить `npm run bot:webhook` и получить подтверждение `success=true`.
2. Запустить бота новым тестовым пользователем и проверить приветствие.
3. Убедиться, что профиль показывает включённые уведомления.
4. Добавить бота в тестовый канал и проверить появление `chat_id` в форме категории.
5. Создать тестовый лид с телефоном, email, ссылкой и `@username`.
6. Проверить, что канал и подписчик получают тизер без исходных контактов.
7. Открыть кнопку тизера и убедиться, что выделена правильная карточка.
8. Купить лид и проверить одно списание, одно сообщение и полный контакт только покупателю.
9. Временно вернуть MAX API `429/5xx` или заблокировать исходящий запрос: задание должно перейти в `RETRY`, а не потеряться.
10. Остановить бота пользователем и убедиться, что новые личные задания пропускаются.

Состояние очереди доступно администратору через `GET /api/admin/bot/status`; реальные токены и ID получателей ответ не раскрывает.

## Откат

Миграция только добавляет таблицы и столбцы. Предыдущую версию приложения можно временно вернуть без удаления данных. Не удаляйте `BotDelivery`, пока в ней есть `PENDING`, `PROCESSING` или `RETRY`: сначала дождитесь доставки либо осознанно отмените задания отдельной миграцией.
